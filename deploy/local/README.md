# Local Deployment

Use local deployment for development only.

Local commands:

1. `./scripts/build-local.sh`
2. `./scripts/run-local-server.sh`
3. `./scripts/test-local.sh`
4. `./scripts/stop-local-server.sh`

Writable local paths:

1. `/tmp/mp-cache/run/`
2. `.tmp/data/`
3. `.tmp/exports/`
4. `logging/`
